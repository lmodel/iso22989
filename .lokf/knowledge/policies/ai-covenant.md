# AI covenant

Whoever submits a contribution owns it, whatever tools helped.[^covenant] In this repository:[^covenant]

- an element names its clause or term and never quotes it;
- no ISO text goes into the schema, examples, docs or bundle;
- no ISO text goes to an AI tool;
- ISO's metadata records are upstream data and are never edited.
